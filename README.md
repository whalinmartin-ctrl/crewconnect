# Apex Protocol — Professional Portfolio Website

A responsive one-page portfolio built with **HTML, CSS and JavaScript**. It uses the Apex Protocol logo, CEO portrait and event photography supplied for the project.

## Project structure

```text
apex-protocol-portfolio/
├── index.html
├── css/style.css
├── js/script.js
└── assets/
    ├── logo/logo.png
    └── images/*.webp
```

## Run in VS Code

1. Open the `apex-protocol-portfolio` folder in Visual Studio Code.
2. Install the **Live Server** extension if you do not already have it.
3. Right-click `index.html` and choose **Open with Live Server**.

No npm install or framework is required.

## Mobile / device support

The layout is responsive for desktop, tablet, iPhone and Android screen sizes. It includes a mobile navigation menu, touch-friendly buttons, responsive photography, reduced-motion support and `viewport-fit=cover` for modern iOS devices.

## Partner logos

The current collaboration cards use clean typographic wordmarks because separate official logo files were not supplied. When you have official transparent PNG/SVG logos, add them under `assets/partners/` and replace the text marks in the `#partners` section.

## Publishing

This site can be deployed as-is to GitHub Pages, Netlify, Cloudflare Pages, Vercel static hosting, cPanel or any normal web host.
